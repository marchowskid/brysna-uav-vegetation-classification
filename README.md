# Brysna UAV Vegetation Classification

Pixel-based vegetation classification of UAV orthomosaics using RGB and HSV thresholding.

This repository contains Python scripts and Jupyter notebooks used to estimate vegetation cover on newly created artificial islands in the Szczecin Lagoon.

## Author
D. Marchowski

## Year
2025

## Methods
Vegetation is classified using fixed thresholds in the HSV colour space (primary method).
An RGB-based classification is included as a complementary sensitivity check.

## Requirements
- Python ≥ 3.9
- numpy
- pillow
- matplotlib
- scikit-image
- requests
